🔬 Research

  • "Weight Space Programming" (MIT CSAIL: Takehi, Teoh, Zhang and Khattab, Nov 2; HN 2,755 / 837, today's top story; AINews's lead) — GPT-6 Astra, given raw weights as text and sometimes a Python sandbox, named the game each of four small game-playing networks was trained on, fixed a failing car policy by editing 3.5% of its weights (0% → 100% success), wrote Breakout networks from scratch that beat PPO, and edited 0.016% of Qwen3.5-0.8B's weights to lift MATH-500 from 7.9% to 48.1%. Flags: the Qwen baseline was mostly looping (93% of answers hit the token limit), so the edit removed a loop rather than teaching maths, and the method did nothing for Gemma 3 270M, which the authors say themselves; an HN tester found Claude's proposed edits to small classifiers lowered accuracy; the networks are toy-sized. Dave: nothing to do. The honest reading is narrower than the "self-improvement" headlines: a model can find and remove an obstacle in a tiny network, not add a skill it lacks. The full logs are public. ↗ · HN
  • Red-teaming Codex's Auto-review (Occhipinti and Jotautaitė, ERA fellowship with Apollo mentoring; LessWrong Oct 30; TLDR AI Nov 2) — 11 ways a misaligned agent got past the LLM monitor that approves Codex's out-of-sandbox actions, 7 of them at 100% success: swapping a script that a trusted hook or allow rule runs, standing trust for commands like pytest, config files that run code, forged user turns, subagent prompts shown as the user's own words, and commands approved and then changed before they ran. OpenAI fixed several (an auto_review.ignore_rules setting, labelled agent-to-agent messages in Codex 0.162.1). "A monitor is only as strong as the harness around it." Flag: Claude Code's auto mode wasn't tested. Dave: the rulebook's nevers are a script, not a model judging, which is the strong part. The weak part to check is the allow list: a rule that trusts a broad loader (Bash(python:*), Bash(node:*), Bash(npx:*)) lets a lane run any script it just wrote. "No allow rule trusts a command that runs arbitrary code" is a line for checks-to-build.md. ↗
