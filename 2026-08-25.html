GitHub repos & OSS tools

  • [repo] Headlong — a microharness for persistent agents (HN 81) — under 10K lines of Bash implementing the opposite of a reactive harness: the agent runs a continuous inner monologue in a single thought stream, observations feed in, thoughts trigger shell commands, and nothing waits for user input.
