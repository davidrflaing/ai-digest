  • [skill] "How the Claude Code team does code review" (claude.dev, Oct 15; Addy Osmani, Morgan Westlee Lunt, Qing Wang; HN 371 / 342) — the engineering post behind yesterday's Code Review GA, and the part you can use without the Team plan.   • Anthropic, "Claude reveals ECDSA curve origins" (Oct 16; HN 900 / 335, the day's top AI story) and "Designing more efficient quantum circuits with Claude" (Oct 16; HN 149 / 32) — the NIST P-curve seeds, rumoured since the 1990s to be hashes of a joke phrase, were outputs of the C library's lrand48 seeded with Unix timestamps between May 1997 and April 1998: Claude hypothesised a weak period PRNG "in under half an hour", noticed the top bits of some seeds were all zero, brute-forced the 32-bit-output states and recovered the prime-curve states with LLL lattice reduction; each recovered state regenerates all 160 bits of its seed; the base points for P-192 and five X9.62 curves came from FreeLIP's generator; reproduction code is published and the $36,864 bounty goes to the Internet Security Research Group.
