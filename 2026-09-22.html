🔬 Research

  • Plugin4Shell: a plugin pinned to a reviewed commit could install different code in Claude Code, Codex, Copilot and Gemini CLI (Air Security, disclosed Sept 17–18) — Git treats a 40-character hex branch name as a branch before it treats it as a commit. So whoever controls a plugin's repo can create a branch named after the pinned SHA and ship different code while the pin still looks valid. With auto-update on, that's zero-click remote code execution with the developer's own permissions. It's fixed in Claude Code 2.1.179 and Codex 0.146.0. Copilot has no patch, and Google won't patch Gemini CLI because it's being retired. GitHub.com rejects SHA-shaped branch names, but Bitbucket and self-hosted Git don't. Dave: the Claude Code here is well past 2.1.179. Check codex --version, because the codex plugin runs the Codex CLI, and don't install plugins from non-GitHub hosts. The same lesson applies to the --accept-command <sha256> pins from Sept 15: a pin only protects you if something checks that the code on disk matches it. ↗
