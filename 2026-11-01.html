🔬 Research

  • Nolan Lawson, "The AI cost of JavaScript frameworks" (Oct 28; HN 112 / 60) — Claude Code on Opus 5.5 (high effort) built the same app in 12 setups, five runs each. Hono+htmx (2.67)andAstro(2.76) were cheapest, Next.js cost $3.14 and shipped the most JavaScript (142 KiB), and Angular cost $4.97 (9.76M tokens, 17 minutes). SvelteKit's $4.28 came partly from the agent reading its v3 migration guide, and he suspects some frameworks' own MCPs and skills cost more than they save. Flags: one small content site, one agent, API-price estimates rather than real spend, and high run-to-run variance. Dave: for the next landing page or the two-offers site, a server-first stack like Astro means less lane time and less JavaScript for a visitor on a phone. Before you add a framework's own skill to a lane, check it doesn't cost more than it saves. ↗ · HN
  • Cisco Talos: the VOLTA infostealer ranks its victims with an LLM (Oct 31; HN 249 / 131) — a Windows stealer that takes browser passwords, cookies and cards, crypto wallets, Slack, Telegram and Discord sessions, Microsoft OAuth tokens, and SSH and cloud keys. It then sends a report to OpenRouter (by default anthropic/claude-opus-4.6, falling back to Kimi K2 and then Gemini 2.5 Flash if refused) asking for a "target assessment", and uses the stolen sessions to pull more, such as Gmail receipts. Flags: Windows only; the way it infects machines isn't known; it's sold as a builder. Dave: nothing to do on the Mac. The point is that a stolen session is now read and priced by a model within minutes, which is the real cost of any third-party app that holds a claude.ai or Gmail login. ↗ · HN
