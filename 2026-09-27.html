GitHub repos & OSS tools

  • [repo] edgelesssys/privatemode-decisions: an MIT Python library that turns any vLLM-served, OpenAI-compatible model into a Jev-style decision model. It numbers the options, prefills the answer, and reads a probability for each option from one output token (HN 103 / 42) — install with pip install git+https://github.com/edgelesssys/privatemode-decisions. It takes about 150 ms per decision, handles up to 191 options, and costs almost nothing but input tokens. On their benchmark, GLM-5.3-Flash run this way matched Jev (median gap 0.7 points, p=0.64), and it can also decide on images, which Jev can't. Honest flags: 16★, "vLLM-backed" means it needs logprobs, so Ollama isn't a guaranteed target, and GLM-5.3-Flash won't run comfortably on a Mac. Dave: this is a third way to shadow-test the comms board's 🔴/🟡/⚪ calls after Kev (Sept 22) and Ollaya (Sept 26). Its edge is that the option list is yours, so it can score the aggregator's exact priority-plus-banner combinations rather than a generic label set. ↗
  • [repo] reladraw/reladraw: a text language for diagrams where you say where things go ("A left of B"). It sits between Mermaid's auto-layout and hand-drawn draw.io, renders to SVG, and ships an agent skill (Apache-2.0; 615★; Show HN 326 / 88) — install with npm install -g reladraw, then give Claude Code the skill with npx skills add reladraw/reladraw -g. The parser, layout engine and renderer have zero runtime dependencies. Honest flag: it's v0.8.0, so expect the syntax to change. Dave: use it wherever Mermaid gives you a layout you can't control. The recovery-journey and funnel flow diagrams in ~/docs/plans are the obvious test, because the order on the page matters there. ↗
