  • "Scaling Discovery Requires Forgetting" (arXiv 2610.20563; Oct 14; Shangyin Tan, Ben Zhou, Lakshya Agrawal and others with Koushik Sen, Alex Dimakis and Matei Zaharia; UC Berkeley, Stanford and Bespoke Labs per secondary coverage; no code link) — one agent running longer, parallel agents, and communicating agents all plateau as history accumulates: each agent anchors on its own past attempts, edits get smaller, and extra compute stops helping; the fix is to periodically discard every agent's session and the candidate history and restart from the best candidate so far (one summary: forget three times, so four rounds), which gives up to 15% over parallel agents and up to 39% over a single agent at the same budget on heuristic programming, kernel optimisation and model training; the authors' line is that what an agent is allowed to remember matters as much as its compute.
