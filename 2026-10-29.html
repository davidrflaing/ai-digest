💼 Business & notable

  • The git, curl and python3 that ship with macOS still trust the compromised eMudhra certificates (Oct 28; HN 1,149 / 399) — the private keys of eight eMudhra intermediate certificates can be recovered from the public certificates. This was disclosed Oct 17–20; Chrome and Firefox blocked them the same day, and Apple's own products on Oct 22. But the developer tools macOS ships read /etc/ssl/cert.pem and still trust them, and macOS 27.2 (Oct 26) undid the manual fix. The risk is someone on the network impersonating an HTTPS host: a clone or pull could carry their code, and a push could leak a GitHub token. The page has a one-line check (git ls-remote against its test repo; an error means you're protected) and a workaround that removes two roots from /etc/ssl/cert.pem with sudo, which you repeat after each macOS update. Flags: the page doesn't say whether Homebrew's git is affected; no exploitation is known; the site is Dennis Jackson's with community contributors, Apache-2.0 on GitHub. Dave: the launchd jobs and every lane use the system git and curl. Run the check yourself on any network you don't control. The fix is a sudo edit to a system file, so it's yours to make by hand, not a lane's. ↗ · Main page · HN
