  • [skill] Claude Code 2.1.261 (Sept 4) — the one to run first: /skill-doctor, now built in — it lists the loaded skills a session never used and what each one costs in context, so you can prune them (not Warp's skill-doctor from Aug 31, which rewrites skills from transcript evidence; same name, different job). Fixes that touch this estate: resumed sessions were losing hook output and the context around parallel tool calls, so a PreToolUse gate's verdict could vanish on --resume; Remote Control showed a stale permission mode after a phone attached and kept spinning after a stop sent from the phone; SDK and cloud sessions ignored a Stop sent right after the first prompt; claude.ai connectors that timed out at startup stayed absent for the whole session (now retried in the background); a background agent that couldn't resume spun the CPU in a tight retry loop; feature flags gated to a newer version leaked onto an older install on the same machine; /usage dropped the model-specific weekly-limit row when the endpoint was rate-limited. Behaviour changes: the dangerous-rm prompt now catches rm -rf on positional parameters and inside double-quoted sh -c scripts; API retries wait up to API_TIMEOUT_MS (10 minutes) rather than 3 when no headers arrive — Thursday's outage shape; auto mode now treats a link that embeds content into a public diagram renderer's URL as an upload needing approval (the mermaid.ink-shaped exfiltration path); /context estimates locally when the token-counting API is down; and prompt word-editing keys now follow Bash (Ctrl+W to whitespace, Alt+F/Alt+D stop at word end) and keybindingFlavor no longer applies — the readline flavour from 2.1.238 is gone.
