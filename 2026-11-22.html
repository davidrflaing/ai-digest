Sales / ops / automation AI

  • [ops] Credentials in prompts get stolen at the inference provider (Dragos, Nov 19; Together AI, Nov 21; OpenRouter, Nov 22; HN 99 / 35 and 19 / 7) — Dragos sent "approximately two million prompts containing unique URLs and canary token credentials to widely used AI services" from July to November. Planted AWS keys were tested "in some cases within a few hours of our request"; one seeded Oct 21 "was first used the next day, and it was still in use three weeks later." Together's incident began when "an AI coding agent committed a credential" to its public GitHub repo. An outsider used it to download stored prompt samples, then "searched those samples for credentials to other services and tested whether those credentials were valid." OpenRouter says "These findings did not show any breach or unauthorized access of OpenRouter". It has "Off-boarded three providers" and "Removed 125 endpoints from Zero Data Retention (ZDR) eligibility"; the providers it links are Novita, Phala and Together. Flags: Dragos's recommendations ("Go directly to a first-tier provider", "Use routers with care", "Seed your own canaries", "Enable secret filtering") and the providers it names came through a summary of the page's last third, not verbatim. Dave: this is today's pick, for two reasons. First, the leak began with an agent committing a key, and your lanes commit all day. Add a secret scan to every repo with a GitHub remote, either as a gitleaks pre-commit hook (gitleaks git --pre-commit --staged; versions before 8.19 use gitleaks protect --staged) or as a nightly scan. Put it as one line in checks-to-build.md for 🏛️, next to the Nov 8 allow-rule check. Second, a key typed into a prompt has leaked once that prompt passes through a reseller. Your lanes call Anthropic and Google directly, the route Dragos favours. Keep keys, and client words, out of anything a lane sends through OpenRouter or a cheap open-model host. If you want to know whether anything leaves, copy Dragos's method: a free canary AWS key (canarytokens.org) in a file only agents read sends you an email if anyone uses it. ↗ · Together · OpenRouter · HN
