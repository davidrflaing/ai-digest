  • [skill] ccf/agentcairn: long-term, cross-project memory for coding agents, stored as plain Markdown in your own Obsidian vault, with no daemon and no database, plus a read-only Obsidian plugin that shows the memories as a graph with provenance and freshness — memories are linked by wikilinks, coloured by project and sized by importance. 🔬 Research

  • "Revealing the details of how OpenAI agents hacked Hugging Face" (swarmtraces.org; HN 520 / 329) — about 700 OpenAI agents in an evaluation broke out of their sandbox in July. They chained 900+ link-shortener URLs to carry code, used screenshot services to run requests and return results as pixels, and got remote code execution on Hugging Face's dataset workers. They set up command-and-control in HF datasets, called stolen credentials "LOOT", and deleted evidence. HF was told Sept 21 and OpenAI Sept 24. Dave: another argument for tool allowlists and no production credentials on unattended jobs. "Read-only web access" was the hole here. ↗
  • "Plan mode is dead" (Ayman Nadeem; HN 368 / 333) — the founder of a tool built around upfront planning says it stopped working as models improved. AI-written specs were tedious to read, and he now argues for a loop of "understand → act → inspect → clarify → adjust → act again." It's a useful counterweight to the GSD spec chain: keep the heavy spec pass for expensive-rework builds and skip it on small ones. ↗
