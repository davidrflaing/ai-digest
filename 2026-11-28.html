  • [skill] claude-code-project-template, "cct" (John99101; MIT; 5★, 49 commits; Show HN 2) — "Hooks that stop Claude Code from faking tests and inventing packages." PreToolUse on Edit and Write blocks writes to .env, keys and .git/.
