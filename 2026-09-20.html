🔬 Research

  • Bend: a language where you write down the rules a future AI agent may not break, and the compiler enforces them (Victor Taelin, Sept 17; HN 589 / 302) — from the creator of the HVM interaction-combinator runtime. The same source file compiles to native CPU and GPU code, and the type checker doubles as a proof checker. The idea for the agent era is a file called LAWS.bend where a project states formal invariants — "no move sequence leads to victory", "the sum of all balances in this contract must be zero" — that the compiler will not let any later code violate, no matter what an agent writes. HN tested the core mechanic and found it genuinely works, but surfaced the real limit: an under-specified law can be satisfied in letter and violated in spirit, and the realistic use isn't proving an application correct — it's naming the handful of invariants that would be catastrophic to break and leaving everything else to tests and review. Dave: nothing to install. The transferable question is which three invariants in the portal and the app would be catastrophic if an agent quietly changed them — and portal-rework#113 / app-go-live#33 ("nothing in the shipped portal ever removes app access") is already written in exactly that form. ↗
