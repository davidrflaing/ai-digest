  • [skill] Gemini Notebook API: NotebookLM's first official API and MCP server (Early Access Public Preview, free during preview; in TLDR AI Nov 4; NotebookLM has been called Gemini Notebook since Jul 16) — REST at notebook.googleapis.com/v1 plus a remote MCP server at notebook.googleapis.com/mcp with seven tools: create, get, list and update notebooks, and create, get and list sources. Sources can be "web pages, YouTube videos, plain text, and Markdown", up to 500,000 words each. Sign-in is OAuth only ("The API doesn't accept API keys"), and the gcloud tokens in the MCP example "expire after one hour". It works with personal Google accounts only: Workspace accounts get 403 WORKSPACE_ACCOUNT_NOT_SUPPORTED, and the account must have opened notebook.google.com once. It can't make anything yet: "Generating artifacts" and "Retrieving information from a notebook" are on the roadmap, with no dates. Flags: no Audio Overview call; no data-use or training statement on the docs pages; no release date or post-preview price.   • [skill] mimic (xatuke/mimic; MIT; 6★, 2 commits; Show HN today) — a skill that turns 2–8k words of someone's writing into a reusable <author>-voice SKILL.md. It measures the text with scripts/stylometry.py (standard library only) and writes to ~/.claude/skills/ only after an explicit yes. The author's own test is the useful part: surface stylometry "cannot reliably tell the skill from plain 'write as X'". The README adds that "Mimic is for style, not deception." Flags: tiny and new; one person's benchmark. Dave: don't install it as a second voice skill. dave-voice already owns your voice, and interview-me puts your own words in the reply. First, its finding is a warning for dave-voice's measured fingerprint: matching the numbers isn't proof a draft sounds like you, so your line-tag review stays the real test. Second, if you want a second measurement, read stylometry.py, then run it with python3 -I on a copy of your own sent lines. Never run it on client messages. ↗ · HN

🔬 Research

  • How much does reasoning effort matter? (Vals AI, Nov 3) — across seven models and eight benchmarks, "Lowering reasoning effort reduces cost much more than it reduces score." "In 22 of 56 cases, a lower setting scored as high at lower cost." Flag: each score uses about half of each benchmark's tasks, so it's noisy.
