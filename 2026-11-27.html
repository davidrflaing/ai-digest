  • [skill] faster-mac-use (lifan-builds/faster-mac-use; AGPL-3.0; 8★, 56 commits; Show HN 3, Nov 26–27) — "fmu lets AI agents drive your logged-in Chrome tabs and native macOS apps in the background", and "Your mouse stays where you left it (0.0 px drift), your active window keeps focus". It's an MCP server (claude mcp add faster-mac-use -- uvx --from faster-mac-use fmu mcp) plus a browser-routing skill that sends each task down one route: CLI or API, transcript tools, search, headless Chrome, your logged-in Chrome, or the native Mac. Flags: it needs Accessibility permission and an unpacked Chrome extension that talks to ws://127.0.0.1:19222, and its Swift helper listens on /tmp/fmu-ax.sock, a path any process on the Mac can see. It can fill payment and sign-in forms, upload files, and turn Chrome extensions on and off. Its README says nothing about telemetry or safety. The speed figures are the author's own. Dave: skip it. Your WhatsApp lane uses a dedicated Chrome profile because an agent in your everyday, signed-in Chrome can reach business Gmail, Meta and GoHighLevel. Worth borrowing for the phone-harness and Playwright notes: one skill that picks the lightest route (API, then headless, then a real browser) before anything takes over a window. ↗
  • [skill] lip-dictation (batanus/lip-dictation; MIT code; 11★; Show HN 16 / 2) — "Talk to Claude Code without making a sound." It's a Claude Code plugin (/plugin install lip-dictation --marketplace batanus/lip-dictation): press the button above the prompt or /lip, mouth a phrase at the webcam, and the text is inserted. "A lip-reading model (Auto-AVSR) runs locally on your Mac: no audio is recorded and no video leaves your machine." The README says "This is a prototype, and accuracy is modest." Flags: the model weights have "no explicit license" and were trained on data whose terms "restrict use to research and non-commercial purposes"; you download them yourself. About 2.5 GB on disk and about 1 GB of memory while it waits. It keeps cropped mouth images and a history of dictated text in ~/.cache/lip-dictation/ until you delete them. Dave: skip it. The weights rule out use in a business, and voice dictation already covers you. ↗ · HN

GitHub repos & OSS tools

  • [repo] Hub by Icons8 (icons8/hub; Apache-2.0; 56★; Product Hunt #1, Nov 26, 377 points) — "Run 100 Claude Code or Codex sessions like 5". "The hub keeps them in order and brings you only the decisions." One coordinator session hands goals to permanent agents, each owning an area, and short-lived executors, each in its own git worktree. Each session is a claude -p process, and you steer from a local web page or a Telegram bot you make yourself, where questions arrive as cards with buttons. It's free, with "no paid tier, no hosted version", and runs on your own subscription. "No telemetry unless you switch it on." Flags: "Sessions run with permission prompts off (bypassPermissions mode, on Claude Code and Codex alike), so treat the hub like a shell on your machine." The hub keeps its own copy of Claude Code, and the README doesn't say whether your ~/.claude hooks, including rulebook-nevers.py, load in its sessions. The local page has no sign-in unless you set a password, and its "Files" view shows the whole disk. It installs by curl … | bash and updates itself every 6 hours. Tools that touch money, production, data or outgoing messages "connect only after your yes". It doesn't accept outside contributions yet. Dave: skip the install. It does the same job as 🎯 and cmux, with the permission layer your rulebook relies on switched off. One idea for 🎯: send each lane's question as a card with the answer buttons on it. That is the WAITING ON block with a reply button, and it would save typing the words a lane asks for. ↗ · GitHub
  • [repo] Pax by Pydantic (beta, Nov 25; Product Hunt #5, Nov 26) — "Pax is the official Pydantic AI coding agent for your terminal: everything is a plugin, you can run your own Pydantic AI agent in it, and its coding agent works in a sandbox of your choice, on any model." It reads AGENTS.md, CLAUDE.md and .claude/skills, imports Claude Code sessions with --resume-claude, and has a -p headless mode. Install: uvx pydantic-ai-pax. Pydantic's own single runs put it level with OpenCode (58.5 against 58.2), and a run with Opus 5.5 inside Pax cost $24.61 against $25.10 in Claude Code. Flags: the licence isn't stated in the article; "the setting for unattended runs that never stop to ask" is Coder(autonomy='max'); tracing goes to Pydantic Logfire through a plugin, and the article doesn't say whether it's on by default; the full method comes "with 1.0". Dave: skip it. As far as the article shows, Pax runs on model API keys billed per token, while your lanes run on a subscription, and the cost gap it reports is 2%. ↗
