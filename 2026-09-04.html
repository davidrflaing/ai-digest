  • "The Harness Playbook" (Can Bölük, stencil.so, Sept 2) — a game-engine-shaped architecture for agent harnesses: one materialised DOM as the authoritative session state ("correctness comes from making non-replayable state unrepresentable"), trusted policy on the host and untrusted execution in a sandboxed stub ("the sandbox should execute, not decide"), stack-based Directors for multi-turn control, model compatibility declared in structured KDL rather than provider-name branches, and a tool surface of a few deep primitives; the numbers: cutting the tool roster from 23 definitions to 5 dropped wall-clock on a task from 86.2s to 36.6s ("every schema taxes every turn"), a streaming render pipeline from 267s to 90ms, and of 78 official SDK examples reviewed, only 2 of the 17 stateful ones were correct.   • Meta Engineering, "An organizational second brain: building an AI that learns from experts" (Sept 2) — a two-layer system: 200+ readable files (positions, taxonomies, routing indexes, gateways) that separate what the agent knows from how it reasons, and a self-improvement loop that compiles expert corrections into minimal file edits — diagnose (knowledge gap or procedure flaw?), propose via sub-agents, independent contradiction review, blind replay to prove the fix, regression across the benchmark, then land with the case added to the suite; dense frequently-used knowledge lives in curated wiki files, sparse material behind semantic search; files declare dependencies in YAML frontmatter.   • Sebastian Raschka on Astra's "recurrent depth" (Sept 2) — looped transformers run the same layer stack more than once (Nanbeige 4.2, the first major open-weight case, runs its 22 layers twice — 44 layers of compute for 22 layers of weights), an idea from a 2024 NeurIPS paper and the mixture-of-recursions line; his read is that the excitement is "a tiny" architectural tweak dressed up, that compute roughly doubles even as storage doesn't, and that the monitorability loss comes from computation moving into hidden state — which any scaling does, not looping specifically.
